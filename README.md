# Materials for MSc in AI for Medicine

By: Zain Arifin, PhD

Scripts, data, and teaching materials for the **MSc in AI for Medicine**  
University College Dublin (UCD) — **2026 Cohort**

This repository supports practical and conceptual teaching components of the MSc AI Medicine programme, with a focus on **scRNA-seq and multi-omics data analysis** using reproducible computational workflows.

---

## Repository Scope

The materials in this repository are designed to:
- Introduce students to **single-cell RNA-seq and multi-omics data analysis**
- Bridge **biological interpretation** with **data science and AI methods**
- Provide hands-on experience using **real life datasets**
- Emphasize **best practices** in preprocessing, quality control, and downstream analysis

## 1. scRNA-seq Preprocessing

Topics covered include:
- Input formats
- Quality control (QC)
- Normalization and scaling
- Batch effects corrections
- Cell type annotations

---

## 2. scRNA-seq Downstream Analysis

Topics covered include:
- Pathway enrichment analysis
- Transcription factors activity inference
- Gene regulatory network inference
- Trajectory analysis (pseudotime)

---

## 3. Multi-omics Integration

Topics covered include:
- Understanding different modalities in omics analysis
- PPI network enrichment
- Matched data integration
- Causal/mechanistic hypotheses based Integration
- Graph based integration
